ClubPass

Attendance that can't be faked.

Run your club's events end to end: registrations, check-in at the door, and certificates for the people who actually showed up.

  1. 1Students register for an event from their own account.
  2. 2At the venue, the organizer's screen shows a QR code that changes every 30 seconds.
  3. 3Each student scans it with their own phone, so a forwarded screenshot is useless.
  4. 4Verified attendees download their certificate as a PDF.

Built with Spring Boot, PostgreSQL and JWT.
